# Andreygaag Quickbrowser

## How do I install these formulae?

`brew install andreygaag/quickbrowser/<formula>`

Or `brew tap andreygaag/quickbrowser` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "andreygaag/quickbrowser"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
